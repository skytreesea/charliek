# 냥(코인) 시스템 설계

## 개요
- **수퍼관리자**: 냥 무한대(∞). 차감 없음.
- **신규 가입**: 기본 **10냥** 지급 (DB 기본값).
- **표시**: 로그인 시 My 버튼 옆에 `🪙 10` 또는 `🪙 ∞` 형태로 표시.

## 차감 규칙
| 행동 | 차감 |
|------|------|
| 마이뮤즈 생성 (코드 진행/가사 악보 생성) | 1냥 |
| 기사 저장 (미리보기에서 "저장" 클릭 시) | 1냥 |

## 부족 시 처리
- 냥이 부족하면 해당 기능 실행 불가.
- **안내 문구**: `"관리자에게 문의하세요."` (redirect + alert).

## 구현 요약

### 1. DB
- `users.coins` (integer, default: 10, null: false)
- 마이그레이션: `db/migrate/20260130000001_add_coins_to_users.rb`
- **적용**: `bin/rails db:migrate`

### 2. User 모델
- `coins_display` → 수퍼관리자면 `"∞"`, 아니면 코인 숫자
- `can_spend?(amount)` → 1냥 이상 사용 가능 여부
- `deduct_coin!(amount)` → 1냥 차감 (수퍼관리자는 차감 안 함)

### 3. UI (레이아웃)
- 데스크톱/모바일 로그인 영역: My 옆에 `🪙 <%= current_user.coins_display %>` 표시.

### 4. 마이뮤즈
- `MymuseController#create`: `authenticate_user!` → `can_spend?(1)` 확인 → `deduct_coin!(1)` → 생성 진행.
- 부족 시: `redirect_to mymuse_path, alert: "관리자에게 문의하세요."`

### 5. 기사 생성기
- `ArticlesController#create` (save_preview 시): `authenticate_user!` → `can_spend?(1)` 확인 → 기사 저장 → `deduct_coin!(1)`.
- 부족 시: `redirect_to new_article_path, alert: "관리자에게 문의하세요."`

## 배포 시
1. `bin/rails db:migrate` 로 `users.coins` 컬럼 추가.
2. 기존 사용자도 마이그레이션 default 로 10냥 적용됨.
